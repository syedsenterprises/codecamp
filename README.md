# CodeCamp — Learn Programming by Building

Live demo site: a programming school with working progress tracking.

**What actually works (in your browser, no server needed):**
- 4 tracks (Web, Python, App Dev, AI) that swap the course list live
- "Mark complete" on any course, with an overall progress bar
- Progress saved in localStorage; terminal typing effect; FAQ accordion

**Honest limits:** static front-end. No accounts, no real lessons, no
payments. Connect a course platform or backend for real enrolment.
